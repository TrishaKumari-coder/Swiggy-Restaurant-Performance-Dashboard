# 📊 Swiggy Restaurant Performance Analysis & Dashboard

## 🎯 Project Overview

This project analyzes restaurant performance across multiple cities using Swiggy-style data. The dashboard evaluates demand, ratings, delivery time, pricing categories, and area-wise performance to identify key business trends.

The objective is to understand:

- Restaurant demand concentration  
- Customer rating patterns  
- Delivery efficiency  
- City and area performance  
- Price category impact on ratings  

The project includes both the raw dataset and a fully developed Excel dashboard with pivot-based analysis.
